abhiram@portfolio:~$ ls ~/projects

Things I've built

One small app, deployed four ways: on my own machine, on a single AWS server, as a full production-style setup, and again as containers on AWS ECS.

crud-app-three-tier

A production-style AWS setup for a small web app: separate web, application and database layers across two data centres, built entirely from reusable Terraform modules and configured automatically by Ansible.

Internet → DNS → Public load balancer (HTTPS)
  → Web servers (nginx) → Internal load balancer
  → App servers (Apache + PHP) → MySQL database
  • Terraform
  • AWS
  • Ansible
  • Highly available
  • No open SSH

crud-app-ecs-three-tier

The same three-layer setup, rebuilt on containers. The web and app layers run as Docker images from a private AWS registry on Amazon ECS, and new versions roll out gradually with automatic rollback if they fail. Database settings are injected when a container starts, so no password lives in code or in an image.

  • Terraform
  • AWS
  • ECS
  • ECR
  • Docker

basic-crud-app-tf

The same app on a single AWS server, with a managed MySQL database and file storage. Database passwords live in AWS's secure store, not in code, and there is no SSH access.

  • Terraform
  • Ansible
  • EC2
  • RDS

crud-app-demo

The starting point: a small PHP and MySQL app where you can create, view, edit and delete records, packaged in Docker to run locally.

  • Docker
  • PHP
  • MySQL
